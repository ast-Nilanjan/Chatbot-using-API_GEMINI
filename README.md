# End-To-End-Gemini-Project
This is an AI-powered chatbot built using Google Gemini API and Streamlit. It allows users to ask questions and get intelligent responses using Gemini's generative AI capabilities.

📌 Features
✅ Interactive Chat Interface using Streamlit.
✅ AI-powered responses from Google Gemini API.
✅ Secure API key handling using .env file.
✅ Simple and lightweight deployment.

🛠️ Tech Stack
Frontend: Streamlit

Backend: Python

API: Google Gemini API

Environment Management: dotenv
